📋 Problem Statement & Objective

Practical 9.3

Requirement: Write a PHP program to make 3 different type of pyramid patterns where number of row is entered by user. Demonstrates nested loops (outer loop for row count, inner loop for column characters/spaces). Generates: 1. Half Pyramid (Right-Angled), 2. Centered Equilateral Pyramid, and 3. Inverted Pyramid.

<?php
/**
 * Practical 9.3: 3 Different Types of Pyramid Patterns
 * Group 10 — Government MCA College, Maninagar (GMCA)
 */

$rows = isset($_POST['rows']) ? (int)$_POST['rows'] : 5;

echo "<h3>Pattern 1: Right-Angled Half Pyramid</h3><pre>";
for ($i = 1; $i <= $rows; $i++) {
    for ($j = 1; $j <= $i; $j++) {
        echo "* ";
    }
    echo "\n";
}
echo "</pre>";

echo "<h3>Pattern 2: Centered Equilateral Pyramid</h3><pre>";
for ($i = 1; $i <= $rows; $i++) {
    // Leading spaces for symmetrical centering
    echo str_repeat("  ", $rows - $i);
    // Stars
    for ($k = 1; $k <= (2 * $i - 1); $k++) {
        echo "* ";
    }
    echo "\n";
}
echo "</pre>";

echo "<h3>Pattern 3: Inverted Half Pyramid</h3><pre>";
for ($i = $rows; $i >= 1; $i--) {
    for ($j = 1; $j <= $i; $j++) {
        echo "* ";
    }
    echo "\n";
}
echo "</pre>";
?>

                    

                


            

        


        
        

            

                
💡 Loop Architecture & Nested Logic

            

            

                
    
                    
  • Right-Angled Half Pyramid: Outer loop runs row index $i = 1 to $rows; inner loop runs $j = 1 to $i printing stars.
    • 
                    
  • Centered Pyramid: Outer loop runs $i = 1 to $rows; first inner step outputs ($rows - $i) spaces; second inner loop prints (2 * $i - 1) stars.
    • 
                    
  • Inverted Half Pyramid: Outer loop begins at $i = $rows and decrements down to 1 ($i--); inner loop prints $j = 1 to $i stars.
