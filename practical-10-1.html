📋 Problem Statement & Objective

Practical 10.1

Requirement: Write a PHP Program to perform following operation on Array where values in array are entered by user:

  • 10.1.1: Print the values of array (using loop & print_r).
  • 10.1.2: Reverse an array (array_reverse()).
  • 10.1.3: Merge two arrays in sorted manner (array_merge() + sort()).
  • 10.1.4: Add values of all elements of an array (array_sum()).

<?php
/**
 * Practical 10.1: Operations on Arrays
 * Group 10 — Government MCA College, Maninagar (GMCA)
 */

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Parse user input strings into arrays
    $arr1 = array_map('floatval', explode(',', $_POST['arr1']));
    $arr2 = array_map('floatval', explode(',', $_POST['arr2']));

    // 10.1.1 Print the values of array
    echo "<h4>10.1.1 Print Array 1 Elements:</h4>";
    foreach ($arr1 as $key => $val) {
        echo "[$key] => $val   ";
    }
    echo "<pre>" . print_r($arr1, true) . "</pre>";

    // 10.1.2 Reverse an array
    echo "<h4>10.1.2 Reverse of Array 1:</h4>";
    $reversed = array_reverse($arr1);
    echo "<pre>" . print_r($reversed, true) . "</pre>";

    // 10.1.3 Merge two arrays in sorted manner
    echo "<h4>10.1.3 Merged & Sorted Array:</h4>";
    $merged = array_merge($arr1, $arr2);
    sort($merged); // Sort ascending
    echo "<pre>" . print_r($merged, true) . "</pre>";

    // 10.1.4 Add values of all elements of an array
    echo "<h4>10.1.4 Sum of Array 1 Elements:</h4>";
    $sum = array_sum($arr1);
    echo "Total Sum = <strong>$sum</strong>";
}
?>
