<?php
/**
 * Practical 10.2:
 * 10.2.1 to print your name.
 * 10.2.2 to print the size of a string. Pass string as an argument
 * Group 10 — Government MCA College, Maninagar (GMCA)
 */

// 10.2.1 Function to print your name
function printMyName($name) {
    echo "Student Name: " . htmlspecialchars($name) . "<br>\n";
}

// 10.2.2 Function taking string as an argument and returning its size
function getStringSize($stringArgument) {
    // strlen() computes length in bytes/characters
    return strlen($stringArgument);
}

// Driver / Execution Logic
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $myName = $_POST['name'];
    $testString = $_POST['testString'];

    // Call 10.2.1
    printMyName($myName);

    // Call 10.2.2 passing string as argument
    $size = getStringSize($testString);
    echo "Passed Argument: \"$testString\"<br>\n";
    echo "Size of String: $size characters\n";
}
?>

💡 Technical Function Analysis

PHP String Measurement Principles:

  1. strlen($string): Counts the number of bytes in a string. For standard ASCII text, this equals the character count.
  2. mb_strlen($string): Multibyte string length (useful for UTF-8 characters like emojis or regional scripts).
  3. Function parameters in PHP are passed by value by default, meaning getStringSize($arg) receives a copy of the string without altering the caller.
