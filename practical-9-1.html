Requirement: Write a PHP program to find max value from the 3 values entered by user. The program receives three numeric inputs from a web form and uses conditional statements (if-elseif-else) to compare the numbers and identify the largest number among them.

<?php
/**
 * Practical 9.1: Find max value from 3 values entered by user
 * Group 10 — Government MCA College, Maninagar (GMCA)
 */

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Read input values sent from HTML form
    $num1 = (float)$_POST['num1'];
    $num2 = (float)$_POST['num2'];
    $num3 = (float)$_POST['num3'];

    // Decision-making logic using if-elseif-else
    if ($num1 >= $num2 && $num1 >= $num3) {
        $max = $num1;
    } elseif ($num2 >= $num1 && $num2 >= $num3) {
        $max = $num2;
    } else {
        $max = $num3;
    }

    echo "Given values: $num1, $num2, $num3<br>";
    echo "The Maximum Value is: <strong>$max</strong>";
}
?>

💡 Algorithm & Explanation

  1. Step 1: User enters 3 values ($num1, $num2, $num3) via the form inputs.
  2. Step 2: PHP checks condition ($num1 >= $num2 && $num1 >= $num3). If true, $num1 is the maximum.
  3. Step 3: Otherwise, check ($num2 >= $num1 && $num2 >= $num3). If true, $num2 is the maximum.
  4. Step 4: If both conditions are false, $num3 must be the maximum.
  5. Built-in alternative: PHP also provides the native function max($num1, $num2, $num3).
