🔢 Practical 9.2: Print 1 to N Numbers with Loops

Download Raw PHP ⬇ Practical 9.2

Problem Statement: Write a PHP program to print 1 to N numbers, where N is entered by user using a for loop.

PHP practical9_2.php
PHP 8.2 
<?php
/**
 * Practical 9.2: Print 1 to N numbers
 * Group 10 — Government MCA College, Maninagar
 */

$n = "";
$output = [];

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $n = isset($_POST['n']) ? (int)$_POST['n'] : 0;

    // Loop: Generate sequence from 1 to N
    if ($n > 0) {
        for ($i = 1; $i <= $n; $i++) {
            $output[] = $i;
        }
    }
}

if (!empty($output)) {
    echo "Numbers from 1 to " . $n . ":<br>";
    echo implode(", ", $output);
    echo "<br>Total count: " . count($output);
}
?>
