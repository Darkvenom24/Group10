🔺 Practical 9.3: 3 Types of Pyramid Patterns with Nested Loops

Download Raw PHP ⬇ Practical 9.3

Problem Statement: Make 3 different types of pyramid patterns where the number of rows is entered by the user using nested for loops.

PHP practical9_3.php
PHP 8.2 
<?php
/**
 * Practical 9.3: 3 Types of Pyramid Patterns
 * Group 10 — Government MCA College, Maninagar
 */

$rows = isset($_POST['rows']) ? (int)$_POST['rows'] : 5;

// Pattern 1: Right-Angled Half Pyramid
echo "<h3>Pattern 1: Right-Angled</h3><pre>";
for ($i = 1; $i <= $rows; $i++) {
    for ($j = 1; $j <= $i; $j++) {
        echo "* ";
    }
    echo "\n";
}
echo "</pre>";

// Pattern 2: Centered Equilateral Pyramid
echo "<h3>Pattern 2: Centered</h3><pre>";
for ($i = 1; $i <= $rows; $i++) {
    echo str_repeat("  ", $rows - $i);
    for ($k = 1; $k <= (2 * $i - 1); $k++) {
        echo "* ";
    }
    echo "\n";
}
echo "</pre>";

// Pattern 3: Inverted Half Pyramid
echo "<h3>Pattern 3: Inverted</h3><pre>";
for ($i = $rows; $i >= 1; $i--) {
    for ($j = 1; $j <= $i; $j++) {
        echo "* ";
    }
    echo "\n";
}
echo "</pre>";
?>
