🔤 Practical 10.2: String Name & Size Passed as Argument

Download Raw PHP ⬇ Practical 10.2

Problem Statement: Write a PHP script that accepts the student name and a string as arguments, and prints the name along with the size of the string using strlen().

PHP practical10_2.php
PHP 8.2 
<?php
/**
 * Practical 10.2: String Name & Size Passed as Argument
 * Group 10 — Government MCA College, Maninagar
 */

function processStringArgument($name, $str) {
    $length = strlen($str);
    $words = str_word_count($str);
    $reversed = strrev($str);

    echo "Student Name: " . htmlspecialchars($name) . "<br>";
    echo "Target String: \"" . htmlspecialchars($str) . "\"<br>";
    echo "Length of String: " . $length . " characters<br>";
    echo "Total Words: " . $words . "<br>";
    echo "Reversed String: " . $reversed;
}

$nameInput = $_POST['name'] ?? "Vaibhav Senjaliya";
$targetString = $_POST['str'] ?? "Government MCA College, Maninagar";

// Invocation passing arguments
processStringArgument($nameInput, $targetString);
?>
