🔢 Practical 9.1: Find Maximum Value of 3 Numbers

Problem Statement: Write a PHP program to find the maximum value from 3 values entered by user using conditional statements (if-else).

PHP practical9_1.php
PHP 8.2 
<?php
/**
 * Practical 9.1: Find maximum value from 3 numbers
 * Group 10 — Government MCA College, Maninagar
 */

$max = null;
$num1 = $num2 = $num3 = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $num1 = isset($_POST['num1']) ? (float)$_POST['num1'] : 0;
    $num2 = isset($_POST['num2']) ? (float)$_POST['num2'] : 0;
    $num3 = isset($_POST['num3']) ? (float)$_POST['num3'] : 0;

    // Logic: Decision Making using if-elseif-else
    if ($num1 >= $num2 && $num1 >= $num3) {
        $max = $num1;
    } elseif ($num2 >= $num1 && $num2 >= $num3) {
        $max = $num2;
    } else {
        $max = $num3;
    }
}

if ($max !== null) {
    echo "Maximum value is: " . $max;
}
?>
