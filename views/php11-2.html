⏰ Practical 11.2: Current Date, Time & Dynamic Greeting

Download Raw PHP ⬇ Practical 11.2

Problem Statement: Display the current date and time in PHP and generate a greeting message (Good Morning, Good Afternoon, Good Evening, Good Night) based on the current hour.

PHP practical11_2.php
PHP 8.2 
<?php
/**
 * Practical 11.2: Date, Time & Dynamic Greeting
 * Group 10 — Government MCA College, Maninagar
 */

date_default_timezone_set('Asia/Kolkata');

$formattedDate = date("l, d F Y");
$formattedTime = date("h:i:s A");
$hour = (int)date("H"); // 24-hour format

// Greeting logic based on 24-hour system
if ($hour >= 5 && $hour < 12) {
    $greeting = "Good Morning! 🌅";
} elseif ($hour >= 12 && $hour < 17) {
    $greeting = "Good Afternoon! ☀️";
} elseif ($hour >= 17 && $hour < 21) {
    $greeting = "Good Evening! 🌇";
} else {
    $greeting = "Good Night! 🌙";
}

echo "<h3>Greeting: " . $greeting . "</h3>";
echo "Date: " . $formattedDate . "<br>";
echo "Time: " . $formattedTime . " (Hour: " . $hour . ":00)<br>";
?>
