📋 Problem Statement & Objective

Practical 9.2

Requirement: Write a PHP program to print 1 to N numbers, where N is entered by user. The program receives a positive integer $n from the user and iterates through a for loop from 1 up to N, printing each number with separator formatting.

<?php
/**
 * Practical 9.2: Print 1 to N numbers, where N is entered by user
 * Group 10 — Government MCA College, Maninagar (GMCA)
 */

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $n = (int)$_POST['n'];

    if ($n > 0) {
        echo "Printing numbers from 1 to $n:<br>\n";
        
        // Loop from 1 to N
        for ($i = 1; $i <= $n; $i++) {
            echo $i;
            if ($i < $n) {
                echo ", "; // Separator
            }
        }
    } else {
        echo "Please enter a valid positive number.";
    }
}
?>

💡 Loop Complexity & Details

Loop Execution Flow:

  1. Initialization: Loop counter starts at $i = 1.
  2. Condition Check: Continues as long as $i <= $n.
  3. Body Execution: Prints current value of $i using PHP echo.
  4. Increment Step: $i++ increments the counter by 1 in each cycle.
  5. Time Complexity: O(N) linear time iteration.
