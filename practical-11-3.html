📋 Problem Statement & Objective

Practical 11.3

Requirement: Create a web page for user profile and execute a PHP file on submission of the form and display the information using PHP. Captures comprehensive user profile data (name, email, enrollment, program, skills, bio) via HTML form, transmits it via HTTP POST, and executes PHP code to parse $_POST variables and display the formatted profile card.

<?php
/**
 * Practical 11.3: User Profile & PHP Form Processing
 * Group 10 — Government MCA College, Maninagar (GMCA)
 */

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Collect and sanitize user input from $_POST
    $fullName   = htmlspecialchars(trim($_POST['fullName']));
    $enrollment = htmlspecialchars(trim($_POST['enrollment']));
    $email      = htmlspecialchars(trim($_POST['email']));
    $phone      = htmlspecialchars(trim($_POST['phone']));
    $gender     = htmlspecialchars($_POST['gender']);
    $degree     = htmlspecialchars($_POST['degree']);
    $semester   = htmlspecialchars($_POST['semester']);
    $bio        = nl2br(htmlspecialchars($_POST['bio']));
    $skills     = isset($_POST['skills']) ? (array)$_POST['skills'] : [];

    // Render Submitted Information using PHP
    echo "<div class='profile-card'>";
    echo "<h2>User Profile Details (Processed via PHP)</h2>";
    echo "<p><strong>Name:</strong> $fullName</p>";
    echo "<p><strong>Enrollment:</strong> $enrollment</p>";
    echo "<p><strong>Email:</strong> $email</p>";
    echo "<p><strong>Phone:</strong> $phone</p>";
    echo "<p><strong>Program:</strong> $degree ($semester)</p>";
    echo "<p><strong>Gender:</strong> $gender</p>";
    echo "<p><strong>Skills:</strong> " . implode(", ", $skills) . "</p>";
    echo "<p><strong>Bio:</strong> $bio</p>";
    echo "</div>";
}
?>
